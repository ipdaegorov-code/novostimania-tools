# Музыка для «Видео дня»

Треки с Pixabay Music (бесплатная лицензия, без указания автора). Из облака Pixabay закрыт защитой от ботов, поэтому треки скачиваются вручную и лежат здесь.

Каждый трек — запись в `library.json`:

```json
{"file": "space_ambient_1.mp3", "mood": ["космос", "наука", "спокойно"], "title": "Название на Pixabay", "start": 0}
```

- `mood` — к каким темам подходит: космос, наука, технологии, экономика, деньги, политика, мир, общество, природа, рекорд, тревожно, спокойно, бодро, торжественно;
- `start` — с какой секунды начинать (пропустить тихое вступление).

Бот выбирает трек по теме видео и пишет в сценарий `"music": "<путь>", "music_start": <start>`.
