# Новостимания — «Видео дня»

Вертикальное видео 1080×1920 на 20–40 секунд с озвучкой диктором, моушн-графикой и субтитрами — о самой интересной новости дня. Тему выбирает владелец. Всё по-русски. Работай из `~/nt` (репозиторий с `nm/` и `clipkit.py`). Ключи модули берут сами — никогда их не печатай.

## 1. Подготовка
- `python3 -m nm.publish check` — если `missing` не пуст, SendUserMessage владельцу и закончи.
- `python3 -m nm.publish max-recent --days 1` — если сегодня уже есть пост с `has_video: true` (видео дня вышло) — закончи.
- `mkdir -p ~/video/today && bash ~/nt/setup.sh ~/video/models` — в конце должно быть «clipkit setup OK». Код движка не переписывай. Не ставится и не лечится одним повтором — `python3 -m nm.publish tg-msg --text "🎬 Видео дня сегодня не соберу: <причина>"` и закончи.

## 2. Тема
Возьми `first_line` сегодняшних постов из max-recent и сделай 1–2 WebSearch о самых обсуждаемых и необычных новостях дня. Выбери 3 кандидата, которые хорошо смотрятся в видео: удивительные, понятные, с цифрами, с хорошими кадрами (наука, космос, технологии, деньги, рекорды, громкие события). НЕ предлагай гибель людей, теракты, катастрофы с жертвами, боевые действия — ВК режет такое в клипах.
`python3 -m nm.approve start`, затем `tg-msg`:
«🎬 Видео дня — выбери тему:
1. <тема>
2. <…>
3. <…>
Ответь цифрой или напиши свою тему. «стоп» — сегодня без видео.»
Жди `nm.approve wait --until <сейчас + 15 мин>`; на каждое сообщение сразу ответ:
- 1–3 → «✅ Делаю видео: <тема>. Пришлю минут через 10–15»;
- другой текст (кроме «стоп») → своя тема владельца (может быть и не новость — правила проверки фактов те же): «✅ Делаю видео на твою тему: <тема>…»;
- «стоп» → «❌ Сегодня без видео», закончи.
Нет ответа 15 минут → «⏰ Беру тему 1: <тема>».

## 3. Сценарий → ~/video/today/scenario.json
Каждый факт и цифру сверь минимум по двум независимым источникам (наука — пресс-релиз института/NASA + СМИ); ничего не придумывай; цифры расходятся — «около», «больше». 5–7 сцен, всего 60–90 слов: разговорный русский, короткие фразы, без канцелярита и оценок. Сцена 1 — хук-интрига до 10 слов. Дальше суть, цифры, сравнение с понятным, в конце — почему это важно или что дальше. «Подписывайся…» движок добавит сам. Образец — `~/nt/example_scenario.json`, формат полей — `~/nt/README.md`.
Формат: `{"badge":"ВИДЕО ДНЯ","scenes":[…],"cover":{…}}`. Сцены: общие поля `type`, `say`, `image`, `label`, `sublabel`, `focus`, `zoom`; `hook` (`title` 2–4 строки по 1–2 слова, `accent`, `subline`; без субтитров), `photo` (`ring`), `stat` (`value`, `decimals`, `prefix`/`suffix`, `caption`, `at_word`), `compare` (`items` 2–3, главный последним, `unit`, `decimals`, `at_word`, `badge`, `badge_word`), `quote` (`text` до ~110 знаков — дословный перевод реальной цитаты, понятной без контекста; `author`).
Правила `say`: числа как `{цифры|словами в нужном падеже}` («почти {22|двадцать два} километра»); латиница по-русски или `{NASA|наса}`; «+» перед гласной — ударение. `at_word`/`badge_word` — номер слова с 0 (каждое `{…|…}` = 1 слово, пунктуация приклеивается; отрицательный — с конца).
ЖИВОЕ ВИДЕО: минимум 2 сцены с движущимся видео, лучше 3–4 (`video`, `video_start`, `focus`; у stat/compare `blur`, `dim`; `callout` {x,y,text,at_word,r,pos} — проверь по превью, что кольцо на объекте). Поиск: `python3 -m nm.photos search --src pixabay --q "…" --video`, `--src nasa --video`, `--src wikimedia --video`; качай `nm.photos get --url … --out ~/video/today/v1.mp4`. Каждый ролик посмотри: 4–6 кадров `ffmpeg -ss <сек> -i v1.mp4 -frames:v 1 f.png` → Read; выбери отрезок без надписей, логотипов и титров.
ЧЕСТНОСТЬ: сток — только иллюстрация темы, не выдавай за съёмку события и не подписывай «NASA»/«съёмка с места», если это не так; не бери «ai generated»; если в сцене назван конкретный объект — в кадре должен быть именно он.
КАРТИНКИ: `nm.photos search`/`get` (фото СМИ, Wikimedia, NASA, официальные сайты); без водяных знаков; людей не изменять; ИИ не использовать; крупные (от 1500 px), разнообразные. Каждую посмотри (Read).
ОБЛОЖКА `cover`: `title` — 2 строки, честный вопрос-цепляшка ([«ЭВЕРЕСТ —»,«МАЛЫШ?»]), `accent:1`. Есть compare — `style:"compare"`, `shape:"mountain"` только для высот гор/вулканов, иначе `"bar"`, `items` с `image` у каждого (у главного — самое эффектное), можно `label`; космос — `space:true` + `ground_image`. Без сравнения — `style:"title"`, `image`, `subline`, `number`, `caption`.

## 4. Сборка (cd ~/video/today)
- Озвучка ElevenLabs: `python3 -m nm.voice make --scenario scenario.json` — пишет voiceover.mp3 и поле `voiceover` в сценарий. Прочитай `text` в ответе: цифры и названия звучат правильно? Ошибка (нет ключа/голоса, API) — не повторяй больше одного раза: убери поле `voiceover`, движок озвучит офлайн-голосом; в превью владельцу допиши «(голос офлайн: <причина>)». После любой правки `say` озвучку делай заново этой же командой.
- Превью: `python3 ~/nt/clipkit.py scenario.json video.mp4 ~/video/models preview` → посмотри `work/pv*.png`: текст не обрезан, ничего не перекрывается, фото по теме, цифры верные. Исправь и повтори при необходимости.
- Рендер: `python3 ~/nt/clipkit.py scenario.json video.mp4 ~/video/models` (3–6 минут, запускай с большим timeout). ffprobe: 1080×1920, 18–45 с, есть звук.
- Обложка: `python3 ~/nt/clipkit.py scenario.json cover.jpg ~/video/models cover` → cover.jpg и cover_thumb.jpg; посмотри: текст не обрезан, верхняя и нижняя четверти без важного текста.

## 5. Одобрение
`nm.approve start`, затем `python3 -m nm.approve video-preview --video video.mp4 --cover cover.jpg --caption "🎬 Видео дня — <тема>. Выкладываем? «да» · «стоп» · или напиши, что поправить (текст, фото, цифры, обложку)"`.
Жди `nm.approve wait --until <сейчас + 20 мин>`, на каждое сообщение сразу ответ:
- «да» → «✅ Публикую», шаг 6;
- «стоп» → «❌ Видео в каналы не идёт», закончи;
- другое → «✅ Принял: <что правлю>…», исправь, пересобери (поменял текст — заново `nm.voice make`; превью → проверка → рендер; только обложка — пересобери обложку), снова video-preview. Не больше 3 правок, дальше — «Больше правок сегодня не успею — «да» или «стоп»?».
Нет ответа 20 минут → «⏰ Время вышло — публикую видео».

## 6. Публикация
Текст caption.txt: «🎬 <заголовок>», пустая строка, 1–2 предложения о сути, пустая строка, хэштег рубрики (без @newsobsession).
- `python3 -m nm.publish tg-video --to channel --video video.mp4 --text caption.txt --thumb cover_thumb.jpg`
- `python3 -m nm.publish max-video --video video.mp4 --text caption.txt`
- ВК (ключ не умеет видео — не пробуй): `python3 -m nm.publish tg-doc --file cover.jpg --caption "Обложка для ВК"`, затем `tg-msg`: «📲 Видео дня для ВК — файл выше. ВК → Новостимания → Клипы → «Опубликовать клип» → от имени сообщества → загрузите видео → «Обложка» → «Загрузить» → файл обложки. Описание:» и с новой строки готовое описание: заголовок + одно предложение + «Подписывайся, чтобы быть в курсе главного» + хэштег рубрики с @newsobsession + #новости #видеодня.
- Отчёт: «✅ Видео дня вышло в Telegram и MAX, для ВК — инструкция выше» или какая площадка и текст ошибки (без ключей).
