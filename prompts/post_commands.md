# Новостимания — команды владельца по картинке

Читай этот файл, только если владелец прислал одну из команд ниже. После выполнения — `square`/`make --style big` по основной инструкции и новый `approve preview`.

   - «наложи флаг(и) …» — `nm.card flags --src post.jpg --out post2.jpg --countries Russia "the United States"` (названия как на Commons).
   - «сделай N флагов / флаги …» — фон: живое фото места или темы (как у карточки) → `nm.card dim --all --k 0.7` → `nm.card flagrow --countries …` → `make --style big`. Синий `navy` — только если владелец написал «на синем фоне» или живое фото не нашлось по 4+ запросам (тогда скажи «живого фото не нашёл, сделал на синем»).
   - «замени фон на …» — только если на фото НЕТ людей: rembg (`pip install rembg onnxruntime --break-system-packages`), подставь свободное фото места или флаг, `make --style big`. С людьми — «Фон на фото с людьми не меняем — могу сделать карточку».
   - «сделай карточку [: <место> + <кто>]» — см. «Карточка».
   - «канва …» / «canva …» — если в запросе реальный узнаваемый человек — «Реальных людей в Canva не генерируем — читатели примут за настоящий снимок. Могу сделать карточку». Иначе ToolSearch «canva generate image» (generate-image, get-generate-image-job, при нужде export-design); нет инструментов — «❌ Canva сейчас недоступна — оставляю прежнюю картинку». Промпт по-английски: SQUARE_1_1, фотореализм или редакционная иллюстрация, без узнаваемых лиц, текста, логотипов, важное в верхних 2/3. Опрос статуса раз в 5–10 с до 3 минут; скачай `nm.photos get`; посмотри; `square` → `make --style big`.

### Карточка
Основа — ЖИВОЕ фото: 1) место события (город, здание, зал: kremlin.ru, whitehouse.gov, Wikimedia), 2) тематика новости; минимум 4 запроса. `nm.card dim --src фон --out bg.jpg` (затемняет верхние 2/3) → `make --style big`. Поверх — бейджи: портрет только официальный или свободный, где человек прямо назван: `python3 -m nm.photos portrait --name "Сергей Лавров" --en "Sergey Lavrov"`. Не опознавай людей по лицу. Затем `python3 -m nm.card badge --card post.jpg --portrait p.jpg --name "Лавров" --out post.jpg --slot 1 --of <число людей>` (для каждого: --slot 1, 2, 3). Нет свободного портрета — карточка без бейджа, скажи почему. «на фоне флаги …» — `flagrow --pos low` поверх живого фона, бейджи сверху. Самопроверка (Read): синий фон без просьбы — ищи живое фото ещё раз.
